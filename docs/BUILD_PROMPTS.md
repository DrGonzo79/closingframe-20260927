# Phased build prompts

1. **Paid concierge:** implement secure CSV uploads, explicit column mapping, exception review and downloadable broker reports. Preserve fixture-driven contract tests.
2. **One live connector pair:** add one CRM and TikTok customer export ingestion with idempotency, OAuth secret storage, tenant boundaries, backfill checkpoints and stale-source alerts.
3. **Trust layer:** add model-versioned multi-touch credit, evidence inspection, manual corrections, audit log and run comparison. Instrument match rate and report use.
4. **Learning loop:** after ten paying customers, extract privacy-safe hook/format features and run broker-approved experiments. AI may draft recommendations only from cited evidence.

For every phase: write failing integration tests first; include nil, empty, upstream-error and duplicate-event paths; test keyboard/mobile flows; document rollback; never claim causality or live integration without proof.
