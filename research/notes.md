# Source notes

## Public concept

- Source: [Video marketing analytics for real-estate brokerages](https://www.ideabrowser.com/hub/ideas/video-marketing-analytics-for-real-estate-brokerages-31270ea8)
- Source date: 2026-09-27
- Core idea: connect each listing video to MLS activity, CRM leads, showings and closed deals so a brokerage can learn which hooks, formats, lengths and property types create business outcomes.
- Timing signal: the source reports real estate as the fourth-most-searched TikTok topic, behind food, fashion and fitness. This is a source claim, not independently verified here.
- Operating thesis: once brokerage and video-platform connections exist, scheduled attribution and agent-generated recommendations can run with limited manual work.

## Access note

The public detail URL returned a Vercel security checkpoint to lightweight fetch and redirected the browser session to login. Scores, keyword data, offer ladder, pricing, growth, difficulty, revenue potential and detailed GTM fields were therefore unavailable and are intentionally not invented. The prototype uses only the publicly available concept and newsletter summary.

## Product interpretation

Views alone are a proxy. The useful object is a transparent evidence chain from a published video to a known listing and timestamped downstream events. ClosingFrame makes that chain inspectable and marks all demo data, attribution and confidence as fictional.
